# بلّط البحر — Ballet l Ba7er

A small 3D browser game set on the Saida corniche. In Lebanon, "ballet l ba7er"
(go tile the sea) is what you tell someone to go do something pointless. Here
you actually do it.

**[Play it →](https://balletlba7er.com/)**

## Stack

- JavaScript, plain scripts, no framework
- Three.js r128
- HTML and CSS
- Web Audio API
- GitHub Pages

Made by [Karim Merhi](https://github.com/Merhii).
