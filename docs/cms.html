Publish to the live game

The game is a static site, so publishing means committing ads.json to its GitHub repository; GitHub Pages redeploys and every player gets the new billboards. You need a fine-grained token with Contents: read & write on that one repository. It is kept in this tab only (sessionStorage) and sent nowhere but api.github.com.

Or skip all this: Download ads.json, drop it into the repo (root and docs/), commit and push.
